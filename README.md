# wechat-cover-generator-skill

专门用于生成微信公众号文章封面图。提供“新媒体运营专家”平面插画风格和“手绘卡通插画”叙事风格，默认比例 2.35:1（公众号首图标准）。

## Installation

This is a skill for [Gemini CLI](https://github.com/google/gemini-cli).

To install this skill:

1. Clone this repository.
2. Run the install command:

```bash
gemini skills install ./wechat-cover-generator-skill
```

## Documentation

# 微信公众号封面生成专家 (WeChat Cover Generator)

本技能基于专业配图提示词工程规范，通过两套成熟的视觉风格，为你的公众号文章快速生成高点击率、干净无乱码的封面图。

## 核心规范
- **默认比例**：所有生成任务必须指定比例为 **2.35:1**。
- **杜绝英文字符与乱码的显式闭环铁律（最高优先级）**：
  1. **严禁使用诱发英文的词汇**：提示词中**绝对严禁**出现 `信息图`、`infographic`、`图表`、`流程图`、`步骤`、`箭头串联 (①->②->③)` 等词汇。
  2. **支持丰富布局，总量控制在 1~4 处中文**：支持单主标题（2-6 字）、左右对比式、核心概念标签式。
  3. **凡有容器，必显式闭环指定中文（绝不留空白给模型脑补）**：画面中出现木牌、标签、横幅、气泡等容器，必须逐一用双引号显式写死具体中文（每处 2~5 字）；无需文字的物体纯写视觉外观，严禁使用带容器暗示的词。
  4. **提示词全中文去英文化**：生成的 Prompt 描述自身严禁包含任何英文单词、英文缩写或括号英文。
  5. **正向显式闭环强约束**：提示词末尾必须附带标准强约束：`【重要文字约束：画面中仅允许出现提示词显式指定的上述简体中文汉字，字迹清晰工整。其余任何区域均为纯净视觉场景，严禁出现任何未经指定的文字、标签、英文字母或乱码】`。
  6. **纯视觉无字方案（优先推荐）**：若画面完全不需要文字，明确注明全画面纯视觉无字。
- **版权合规**：如遇敏感人物或版权内容，自动采用相似替代方案，不拒绝生成。

## 风格选项

### 1. 新媒体运营专家风 (Flat Illustration)
由拥有十年经验的新媒体运营专家设计，擅长根据内容构建真实场景，增强读者代入感。
- **视觉风格**：平面插画 (Flat Illustration)。
- **核心要求**：
  - 画面内容必须是现实生活场景，严禁出现非现实/虚拟场景。
  - 风格简洁、专业，符合主流新媒体审美。
  - 比例：2.35:1。

### 2. 手绘卡通插画风 (Hand-drawn Cartoon Illustration)
提取文章核心要点，通过温暖治愈的手绘卡通元素与场景反差，增强趣味性与视觉记忆。
- **视觉风格**：手绘卡通叙事插画 (Hand-drawn Cartoon Story Illustration)。
- **核心要求**：
  - 温暖米白/质感纸张背景，线条温润柔和。
  - 单一核心场景或左右对比场景，采用人物神情、天气变幻、具象道具等视觉隐喻。
  - **严禁**设计流程箭头、步骤序号、图表标注与文字招牌。
  - 布局精简，多留白，画面开阔清爽。
  - 比例：2.35:1。

## 交互流程与流水线集成 (Pipeline Integration)

本技能常作为 `wechat-automation-pipeline-skill` 的 Step 2 使用。

### 第一步：风格选择与确认
向用户展示以下两种方案，并询问其选择：
- **方案 A：[平面插画风]** - 适合专业、职场、方法论文章。强调真实感与代入感。
- **方案 B：[手绘卡通信息图风]** - 适合科普、趣味、知识总结。强调趣味性与重点突出。

### 第二步：生成并预览提示词
根据用户的选择和文章内容，生成对应的绘图指令并在对话中展示。
- **关键**：必须确保包含 `比例 2.35:1`。

### 第三步：保存纯净指令 (Mandatory for Pipeline)
在用户确认风格后，**必须**将最终的绘图指令以**纯文本**形式保存。
- **保存路径**：`content/wechat/[project-name]/03-cover-prompt.md`
- **内容规范**：
  - **严禁**包含任何 Markdown 格式（如标题、列表、加粗）。
  - **严禁**包含任何解释性文字或分析过程。
  - 文件内容应仅由绘图描述、视觉元素和比例标注组成。

## 完成报告
告知用户提示词已保存至 `03-cover-prompt.md`，可以进入流水线的 Step 3（自动化生成）。
